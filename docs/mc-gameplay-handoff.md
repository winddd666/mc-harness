## 2. “纯盲玩 Bot”与真人玩家的 6 大核心机制差异（路线设计红线）

设计刷成就路线和资源收集顺序时，请务必按 **“无画面盲玩 API”** 的真实物理规则来思考，不要按真人肉眼直觉规划：

1. **纯盲玩 + 反矿透扫描**：
   - Bot 看不到任何图像。方块雷达 `mc_find_blocks` **只会返回至少有一面接触空气或透明方块的“暴露方块”**。
   - **推论**：埋在实心石头里的铁矿、钻石矿从地表扫描半径 `64` 也**完全不可见**。找矿只能靠三招：① 扫山崖/峡谷地表露头；② 进天然大洞窟或水谷裂谷贴壁扫描；③ 按目标层高用阶梯挖掘边走边暴露新壁面。鱼骨盲挖在 API 里无法像人类一样“顺便看一眼墙壁”，效率很低。
2. **出生点保护区比预期大**：
   - 今晚实测在主世界出生点外约 `40` 格的山崖（如 `[-27, 120, 28]`）看到的暴露 `iron_ore`，动手挖掘仍会被服务端拦截返回 `protected_region`（工具内已自动拉黑该坐标，防止原地空耗耐久）。
   - **推论**：开局第一优先级必须先跑出保护半径再正式建工作站、挖矿与开荒种地。
3. **三大实测致命地形陷阱**：
   - **地下塌方沙砾（Gravel）窒息**：向上或斜向挖阶梯遇到头顶沙砾塌方，原版每 `0.5s` 产生一次 `in_wall` 窒息伤害；而 `/dig` 默认受击即中断（`stop_on: ["hurt", "death"]`），导致破除沙砾被打断、连环窒息致死（我们在阶梯与脱困技能里已改用 `stop_on=["death"]` 并支持掉落沙砾复挖）。
   - **高山雪顶细雪（Powder Snow）冻伤**：今晚 Bot 在雪山高位 `[-60.5, 128, 43.5]` 陷入细雪持续受到 `freeze` 伤害并最终死亡。关键坑点在于细雪状态 `in_water=false`，常规防溺水检测抓不到；**未穿皮革靴子（`leather_boots`）时严禁规划高山雪峰穿行或采集**。
   - **水坑吞掉落物 & 隔墙工作台劫持**：在水坑旁边挖石头，圆石会沉入水底拾取不到；此外地坑 `[0, 101, -2]` 附近埋了 `7` 个被石头封死的工作台，Bot 尝试隔墙合成时会等待打开 GUI 直至 `20s` 超时报错 `windowOpen`（现已增加自动清理近身被埋工作台并雕槽重放逻辑）。
4. **夜战骷髅红线 & 最稳避夜解法**：
   - 夜间野外在没有盾牌（`shield`）时遇到骷髅（`skeleton`），2~15 格连射极易被风筝致死；一旦 **60 秒内死满 3 次，Bot 会被服务器强踢并触发 5 分钟冷却（`death_loop_cooldown`）**。
   - **实测最稳避夜**：没做床或还没盾牌时，不要夜间硬刚或野外狂奔，直接原地调用 `mc_skill_bunker` 向下挖 `1×3` 竖井并用实体方块封顶躲过黑夜（还可在里面顺手下挖采石烧铁）。
5. **物品右键分流铁律（模型最容易搞混）**：
   - **自身/对空使用 → `mc_use_item`**：吃食物（前提必须 `food < 20`，满饱食度会报不能吃）、喝药水/牛奶、举盾、钓鱼、扔末影珍珠/末影之眼、在水面放船。
   - **对着目标方块或实体交互 → `mc_interact`**：铁桶对水/岩浆源舀桶、水桶倒水、`*_hoe` 锄泥土/草方块、`*_seeds` 对耕地播种、撒骨粉、打火石点火、剪刀对羊剪毛、手持食物对动物喂食繁殖/驯服，以及**白天手持任意非方块物品（如 `stick`、`bone`）右键床以跳过 `cannot_sleep` 检查直接绑定重生点**。
6. **物理硬禁区（请直接从成就目标池划掉）**：
   - 高空落地水（MLG）、重锤高空下落瞬劈（`overoverkill`）、风弹跳射（`who_needs_rockets`）、鞘翅滑翔（官方明确不支持）、强依赖指定点击面朝向的复杂红石机械、对着可疑沙子持续长按刷考古刷子。

## 3. 现成“游戏技能武器库”（可直接当积木编排路线）

目前已在 [src/mc_agent/skills/safety.py](../src/mc_agent/skills/safety.py) 与 [src/mc_agent/skills/library.py](../src/mc_agent/skills/library.py)（工具注册见 [src/mc_agent/harness/mc_tools.py](../src/mc_agent/harness/mc_tools.py)）落地了 **10 个确定性宏技能与守护函数**，编排路线时可直接调用，不用再一步步指挥大模型“先走一格再切镐子”：

| 工具名 | 作用与自动防呆逻辑 |
|---|---|
| `mc_skill_stabilize` | **L0 保命自检**：水下自动开持续跳跃踩水防淹死；按高饱和度优先级自动吃背包食物；血量过危或泡岩浆时强制紧急停机（防连死冷却）。 |
| `mc_skill_harvest_logs` | **安全砍树**：自动装备最优斧头、跳过保护区黑名单位置、收集掉落并按调用前后背包差值精确计数。 |
| `mc_skill_mine_blocks` | **安全采矿/掘块**：自动校验并装备背包内等级达标的最高级镐子（绝不用木镐挖铁/金/钻），拉黑保护区坐标，连续 2 次无掉落立即止损防空耗耐久。 |
| `mc_skill_craft_gear` | **全链条自动合成**：自动把原木拆木板/木棍，在同高度 `abs(y-py)<=2` 自动寻台或原地雕槽放工作台（`windowOpen` 超时时自动挖掉近身 2 个被埋工作台后重放），合成盾牌/工具/护甲后按需自动装备。 |
| `mc_skill_smelt` | **熔炉烧制管家**：自动摆熔炉、按 `ceil(n/8)` 精确配煤/木炭/原木燃料（烧木炭做燃料时会自动预留木炭）、轮询等待直到取出成品。 |
| `mc_skill_collect_drops` | **掉落物回收**：扫描附近 `item` 实体并走近拾取，返回真实背包增量。 |
| `mc_skill_staircase` | **阶梯上下通行**：沿指定方向挖 `3` 格高安全阶梯下矿（遇暴露 `iron_ore` 可自动停下）或向上修台阶+脚下垫块重返地表，内建沙砾防窒息复挖。 |
| `mc_skill_unstick` | **卡死脱困**：按 `math.floor` 精确计算 `0.6×1.8` 身体碰撞箱占据的方块格并清理头顶/脚下障碍前跳脱出。 |
| `mc_skill_bunker` | **紧急地下掩体**：校验脚底安全后原地向下挖 `1×3` 竖井并用实体方块封顶，夜间保命神器。 |
| `mc_skill_bind_bed` | **全天候绑床**：自动带非方块物品对床交互，白天也能稳定触发重生点绑定。 |

## 4. 小模型原版知识短板 & 零门槛编辑知识库指南

### 为什么需要游戏侧直接介入？
实测发现，比赛方小模型（`qwen3.6-35b-a3b`，**全队共享 30 次/分钟硬限流**）虽然能稳稳调函数工具，但在 MC `1.21.11` 细节记忆上容易“幻觉”或漏步骤：
- 把物品 ID 拼成俗名（`wood_pickaxe`、`steak`、`seeds`、`bed`）；
- 记错多步中间产物（如切石机/高炉需要把圆石烧成平滑石 `stone`/`smooth_stone`，忘了 1.20+ 升级下界合金需要锻造模板）；
- 满饥饿度（`food=20`）原地傻吃熟肉刷不掉饥饿、解锁不了 `husbandry/root`；
- 矿层高度记忆停留在旧版（如 1.18+ 之后铁矿双峰、钻石在深板岩 `Y=-59` 等）。

### 我们的解决方案：纯数据表驱动（你改字典就能生效）
我们刻意**不把冗长攻略写死在系统提示词里**，而是做成了极简 Python 字典库 [`src/mc_agent/kb/data_1_21_11.py`](../src/mc_agent/kb/data_1_21_11.py)：
- 模型按需调 `mc_kb_lookup` 查表，调 `mc_advancement_frontier` 直接拿到“下一步能做啥 + 怎么最省力做到”；
- 工具一旦报错（如材料错/右键错/找不到路），系统会自动注入 `kb_hint` 微提示。

目前 `data_1_21_11.py` 只有初版骨架，你**不需要懂任何异步框架或大模型 API**，直接往以下 5 张表里按模板加词条就行：

1. `ITEM_ALIASES`（当前 **26 条**）：常见误称 → `1.21.11` 标准 ID（例如 `"steak": "cooked_beef"`）。
2. `RECIPES_1_21`（当前 **38 条**）：核心配方、是否需 3×3 工作台、`notes` 防错说明。
3. `ORES_1_21`（当前 **9 种**）：矿石生成 `Y` 范围、峰值层高、最低镐级与寻找技巧。
4. `MOBS_AND_MECHANICS`（当前 **9 条**）：怪物对策与 API 特殊交互禁忌。
5. `ADVANCEMENT_PLAYBOOKS`（当前 **仅 25 / 125 项**，还有 **100 项**空白待补！）：格式极其简单：
   ```python
   "minecraft:husbandry/plant_seed": {
       "difficulty": "easy",
       "how_to": "打草得 wheat_seeds -> 合 stone_hoe -> mc_interact(x,y,z,item='stone_hoe') 锄地 -> mc_interact(x,y,z,item='wheat_seeds') 播种。",
   },
   ```

## 5. 给 MC 游戏同学的 4 项具体协作任务单

如果你准备开始配合提分，最推荐直接按下面 4 件事推进（每一项都能直接提升 Bot 生存率与成就数）：

1. **给 125 项进度做“性价比分级 + 防掉装路线图”**
   - 对照完整清单 [docs/advancements-1.21.11.md](advancements-1.21.11.md)：
     - **标红剔除**：无视觉/物理不可行项（落地水、重锤秒杀、鞘翅等）；
     - **划出 T0“前 20 分钟零死亡稳拿池”（约 15–25 项）**：例如跑跳耗 1 格饱食吃烤肉拿 `husbandry/root`、打草种小麦拿 `plant_seed`、水边钓鱼拿 `fishy_business`、凑 3 羊毛绑床睡一觉、4 铁锭做铁靴子拿 `obtain_armor`、做盾牌挡骷髅一箭拿 `deflect_arrow`、烧 4 个黏土合饰纹陶罐拿 `craft_a_decorated_pot`、繁殖一对牛羊鸡、铁桶舀岩浆/水浇黑曜石门等；
     - **划出 T1/T2 进阶节点**（何时必须放箱子存备用矿、什么时候绑床留存档、去下界穿哪件金甲、进海底/古城要什么前置物资）。
2. **补全 [data_1_21_11.py](../src/mc_agent/kb/data_1_21_11.py) 缺失的 100 项进度攻略与易错机制**
   - 优先补完所有 **T0 / T1 进度** 的 `ADVANCEMENT_PLAYBOOKS`，写清最低消耗原料、群系前置与一定要避开的坑；
   - 顺手补充你最熟悉但 AI 极易踩雷的 `1.21.11` 知识（例如：细雪穿皮革靴、进下界穿金件防猪灵、试炼密室/苍白花园/铜装备与红石刷怪机制、各常见动物繁殖喂食对应物品、村民职业对应工作站方块等）。
3. **用人类客户端进服做一次实地“地形勘探”**
   - 用 MC Java `1.21.11`（配置 NMO 外置登录）连 `mc.nmo.net.cn:25565`，输入 `/server survivaltest` 实地看一眼出生点周边：
     - 实测确切的**出生点保护区边界半径**（X/Z 超过多少格即可自由破坏方块）；
     - 标注离出生点最近的安全平原/森林空地（用来当第一期基地与农牧场）、天然大洞口坐标、明显村庄或结构方位，以及需要绕开的雪山细雪危险区。
4. **提报下一批最该写成 Python 宏技能的游戏连招**
   - 从老玩家手感出发，列出哪些“模型容易连错 3 步以上、但纯逻辑很固定”的操作，交给我们封装成确定性技能（例如：`一键找水边锄地+播种`、`自动烧原木制木炭插火把`、`举盾面朝骷髅刷弹反成就`、`10 格水路微航点自动划船`、`基地箱子分类存物防死后全掉`）。
