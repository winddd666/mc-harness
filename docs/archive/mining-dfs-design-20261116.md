## 2. 第一阶段：长程不中断底座收口清单（Phase 1，优先落地）

目标：彻底消除已知死锁与无效消耗，使任意小模型长跑不再触发可预见的 30s 超时断线或原地干耗。

1. **合成与熔炉取物前的空槽可行性硬预检（杜绝 30s 挂死）**
   - 在 `MacroSkills` 与底层 `/craft` / `/window/act(take)` 入口前校验：若 `empty_slots == 0`，且本次操作既不能把某组物品堆叠合并（输出同类未满堆）、也不会把任何消耗槽刚好清零腾槽，则**先执行安全腾槽或毫秒级返回 `inventory_full`**，严禁再向服务端发送必挂死的请求。
2. **技能入口确定性静默腾槽守卫（Auto-Trash Guard，不膨胀工具数）**
   - 在 `craft_gear`、`ensure_crafting_table`、`smelt_items`、`mine_blocks`、`harvest_logs` 开始或产前检查 `empty_slots < 2` 时，自动调用底层 `POST /drop` 清理**确定性低价值杂物**：
     - 第一梯队（纯杂物）：`wildflowers`、`leaf_litter`、`rotten_flesh`、`short_grass`、多余 `sapling` / `seeds` 等；
     - 第二梯队（超配额废石）：例如 `cobblestone` 保留 3 组（`<= 192` 块）、零散多余 `diorite` / `granite` / `andesite` / `dirt` / `gravel` 自动丢弃腾出 2–3 个周转空槽；
     - **硬红线**：绝不丢弃任何工具、武器、护甲、矿石、粗矿/锭、煤炭/木炭、原木/木板/木棍及食物。
3. **`dig_staircase` 参数容错与上行默认免打断**
   - 调用 `dig_staircase` 省略 `direction` 时，不再死板默认 `"north"`，而是优先使用当前未失败的可行方向（通过局部探针择优）；
   - 当 `vertical == "up"`（脱困/上行返程）时，`stop_on_ore` 默认行为应为 `False`（除非显式指定 `True`），避免每 3 步被沿途矿脉打断；
   - `ore_detected` 的 `hint` 明确列出最近矿点坐标、所需 `mc_skill_mine_blocks(block_types=[...])` 与继续赶路参数 `stop_on_ore=false`。

## 3. 第二阶段：路径压缩 `MiningDFS` 与 Harness 空间记忆组件（Phase 2）

核心思路：**代码状态机负责“搜索树压栈/弹栈与航点无损回溯”，模型负责高层阶段目标（找什么矿、何时升镐/补给、何时结束）**；同时避免每格建节点导致图膨胀。

### 3.1 路径压缩与 3 类决策节点

连续无分叉的阶梯或直巷**整段压缩为一条边（Edge）**，边内部每隔 `6–8` 格记录稀疏航点 `waypoints` 供零损耗 `move_to` 退回，绝不在中间每一格建决策节点。全矿井拓扑仅保留 **3 类决策节点**：

| 节点类型 | 生成时机与位置 | 候选分支（有限枚举） | 职责边界 |
| :--- | :--- | :--- | :--- |
| **`Root / Collar` 井口根节点** | 地表安全点开井下矿处（全井唯一） | `[down_N, down_S, down_E, down_W]` 初始下井朝向 | **仅用于跨层往返**（地下彻底断木/断粮回地表，或死亡重生后顺活跃栈航点 0 挖掘返岗）。**不负责日常合成与冶炼**。 |
| **`Switchback Landing` 受阻转角平台** | 阶梯直奔目标深度 `Y_target` 途中，因撞到溶洞悬崖、流体、基岩或塌方被迫停稳的位置 | `[左右 90° 下探, 水平绕障平推]`（自动排除来路） | 类似楼梯转角休息平台；四向均不通即触发向父节点回溯。 |
| **`Spine Junction` 目标层鱼骨枢纽** | 抵达目标矿层（如铁层 `Y=16`、钻石层 `Y=-54`）后，沿着主干道每隔固定跨度（`8–12` 格）落点 | `[左支巷(定长叶子边), 右支巷(定长叶子边), 主干前推一段]` | 左右支巷直接作为叶子边不再继续分叉，防止挖成迷宫且保留隔怪岩壁。 |

### 3.2 节点不变量（Node Invariant）与 5 项标准微操作

**核心不变量**：任何节点或边上动作执行结束后，角色必须满足：**回到节点中心锚点 `anchor`、脚下为实心方块、侧壁通往无光洞穴的破口已封堵、背包保有周转空槽**。

1. **路边采矿内联钩子（`Vein Hook`，不入栈分叉）**
   - **锁锚点 & 验镐级**：记下主干站立格 `anchor`；若遇到当前镐等级不够挖掘的矿（如石镐见钻石矿），不强挖，仅记录坐标待升镐后再采。
   - **六面漏液安检 + 悬空矿托盘（Catch-Block）**：挖掘前先探目标矿背面/上方流体；并检查 `[ox, oy-1, oz]` 是否为空气悬空，若悬空且旁边有依附面，**先垫 1 块 `cobblestone` 做托盘再开挖**，防止 `raw_iron` / `diamond` 坠入深坑。
   - **归位封口**：连通采掘小簇矿并完成微步拾取后，调 `move_to(anchor)` 站回主干原位；若挖掘侧壁掏出了洞穴破口，顺手用圆石封死。
2. **受阻转角封口与剪枝**
   - 阶梯或支巷撞上暗黑溶洞或悬崖停步时，优先拿 1–2 块 `cobblestone` 封堵面前破口（防洞内骷髅/僵尸偷袭），将该分支标为 `pruned`，再枚举左右 90° 转角分支。
3. **主干枢纽低频内务**
   - 在每个 `Spine Junction` 落点时顺手检查 `empty_slots < 3` 静默腾槽、有火把时插 1 根照明防背后刷怪、检查全身镐剩余耐久是否低于返程/补镐红线。
4. **航点倒序无损回溯（`Backtrack`）**
   - 当前节点所有候选边均耗尽或 `pruned` 时，`pop()` 当前节点，沿 `reversed(waypoints)` 倒序调 `move_to` **零挖掘成本退回父节点**（遇偶发沙砾塌方仅精准清障挡路单格，绝不反方向瞎凿新隧道）。
5. **就地壁龛工坊（In-Situ Alcove，零寻找成本）**
   - 日常合成与烧制**不去远处井口寻找旧工作台/熔炉**，仅扫描当前节点 `radius=4` 内是否有现成可用；
   - **熔炉**：直接使用背包泛滥的 8 块圆石在侧壁现掏壁龛放置烧制，烧完取走产物直接前进（同时天然消耗多余圆石）；
   - **工作台**：若包内原木充裕（如 `>= 4`）可就地放置留置；若原木紧缺（如 `< 4`），用完顺手 `dig` 收回背包循环携带，保证一块木头穿行整条地下路径。

### 3.3 高层控制权移交时机（仅 4 类战略中断交还模型）

路径压缩 DFS 接管“下井 -> 转角 -> 鱼骨铺开 -> 遇洞封口 -> 无损回溯”后，仅在以下 4 种事件发生时暂停并向大模型汇报状态（单步执行保持在 ~8–15s 粒度以保证守卫抢占与直播可观测性）：
1. **配额达成**（目标矿石数量已入包）；
2. **工具/资源门槛触发**（如发现高阶矿但缺对应镐级、原木/火把耗尽或总耐久触及红线）；
3. **生存/战斗突发中断**（遇怪受击或饥饿需要处理）；
4. **整井彻底枯竭**（回溯到 `Root` 井口且四个主朝向全 `pruned`，提示换点重开新井）。
