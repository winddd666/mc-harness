# 同层短矿道技能

实机轨迹 case03 中，Bot 已有石镐并看见矿石，但隔墙寻路不能自动挖掘，随后陷入扫描、寻路失败与手工挖掘循环。`mc_skill_tunnel` 用有界的同层开凿填补这个动作缺口，不负责完整矿脉规划。

调用示例：`mc_skill_tunnel(direction="east", steps=3, stop_on_ore=true)`。方向对应 north=-Z、south=+Z、east=+X、west=-X；1–8 格，总预算35秒。只开两格高通道，不挖脚底、不架桥、不跳跃，路径失败后直接返回。矿面在前方时默认停止，再交给采矿技能。

每格先确认实体地板，检查将暴露的邻格流体与沙砾、前方方块白名单和镐等级；先挖头部，再挖脚前。每次挖掘后验证方块确实变为空气，移动后读取 status 确认实到且高度不变。受伤、换身体、离地、进水或动作失败时返回 requires_replan。挖掘 collect=false，走入通道时自然拾取；gained 只来自前后背包差值。

限制：它不保证怪物隔绝，不会绕过障碍或在没有安全地板的洞穴上架桥。流体预检是当时的局部观察，不能保证远处流体不会随后流入。35秒预算在API调用之间检查，单个请求仍受API/客户端时限约束。离线测试覆盖负坐标、虚假移动、受伤中断、矿物等级、流体、落沙和非自然方块；实机验证另见实验 case06。
